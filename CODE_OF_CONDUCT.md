# Code of conduct

We want this project to be a friendly place to learn and to build something useful. Everyone taking part — in issues,
pull requests, discussions and any other project space — is expected to:

- **Be respectful.** Disagree with the idea, not the person. Assume good faith; people come with different experience
  and different first languages.
- **Be constructive.** Say what would make something better. Review the code, not the coder.
- **Be welcoming.** Answer beginner questions kindly. Don't harass, demean, or discriminate against anyone for who they
  are.
- **Respect privacy.** Don't share other people's personal information, and don't paste your own account numbers,
  holdings or API keys into issues.

## Not okay

Harassment, personal attacks, sexualised language or imagery, trolling, and publishing private information.

## Reporting and enforcement

If something isn't right, report it privately through GitHub (the repository's *Security → Report a vulnerability* form
reaches the maintainers, or contact a maintainer directly). Maintainers may edit or remove comments, close threads, and
temporarily or permanently ban anyone who breaks these rules. Reports are handled in confidence.

This code of conduct is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org).
